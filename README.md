# 英文複習 PWA 第二版

繁體中文、免登入、免後端的單字／片語／分級單字／文法原題練習。網站可直接部署到 GitHub Pages 根目錄，不需要 Node、npm 或建置。每位使用者自行匯入資料，題庫與學習紀錄只保存在自己的瀏覽器。

## 第二版改了什麼

- 大檔案改由 Worker 分段讀取，不先在主畫面載入整份 23 MB CSV。匯入時略過逐次來源與各年統計等大量欄位；驗證完成才原子替換，失敗仍保留舊題庫。
- 不再顯示「語境出處」「來源位置」「各年出現次數」的原始 JSON，既有第一版匯入資料也會隱藏。
- CEEC 改以「大考中心詞彙級別」顯示。CEEC 是大學入學考試中心；詞彙分級的來源不代表中文翻譯也由該中心提供。
- 答對後不再重複顯示「你的答案」。
- 單字、片語與分級單字增加「發音」按鈕，使用裝置的離線英文語音。
- 新增「依級別複習單字」，可選第 1–6 級。這個模式只顯示中英文、發音及學習進度，不顯示語料來源或頻率。
- 單字與分級單字預設排除虛詞作為測試目標；不刪掉原資料與歷史，設定可以取消排除。
- 文法改成原始填空題與原有選項，文法名稱只用於分類。匯入正式答案對照後，只有來源、年度、題號及選項都能對應的題目才自動判分。

## 第一次使用

1. 在「設定與匯入」分別選取單字、片語、文法與分級單字 CSV，等到顯示「已匯入 N 筆」。只需選檔一次，以後自動載入。
2. 文法另有「正式答案對照 CSV」匯入區；它不是把答案 PDF 直接丟進網站。PDF 需先整理成核對完成的對照檔。
3. 回首頁選題庫，安排練習。單字／片語／分級單字支援「看中文 → 輸入英文」與「看英文 → 四選一中文」。
4. Android Chrome 可從選單安裝／加到主畫面；iPhone Safari 使用分享 → 加入主畫面。請先等下方顯示「離線資源已就緒」再關閉網路。
5. 定期匯出完整 JSON 備份，並確認下載成功。CSV 清單匯出只供閱讀，完整還原必須用 JSON。

**不會自動同步。** 換手機、清除網站資料、無痕模式或瀏覽器回收空間，都可能影響紀錄。安裝到主畫面及「要求瀏覽器保留資料」不等於雲端備份。

### 發音

只選取系統回報為本機的英文語音，不把詞條交給網路 TTS 服務。如果按下後顯示沒有離線英文語音，請先在裝置的語音／朗讀設定下載英文語音，再回來重試。可用的聲音與離線支援依瀏覽器、系統及已安裝語音而異。

看英文選中文時可直接朗讀；看中文輸入英文時，評分後才提供朗讀，避免事先透露答案。下一個朗讀或切換頁面會停止上一段。

## 出題、虛詞與進度

- 預設每日不同項目目標：單字 20、片語 10、分級單字每級 20；優先舊題分別 5、3、5。都是可調整的安全整數，沒有額外隱藏題數上限。
- 答對與答錯舊項目預設都納入。有足夠舊題時先滿足設定數量，其餘優先新題；不足就如實顯示數量，不拿被關閉的狀態補題。
- 新題按數值頻率排序、同頻率按穩定 ID 排序；分級題庫不含頻率，按穩定 ID 排序。曾作答的詞條不再算新題。
- 分級模式按所選級別計算每日剩餘目標。多級別詞條會在任一所屬級別篩選中出現，但同一天同一詞條仍只有一份作答紀錄，不當作新的未練習項目。
- 虛詞以冠詞、代名詞、介系詞、連接詞、助動詞等功能用法為主。依明確標記、詞性與保守詞表判斷；兼有實詞用法的詞保留。不排除所有動詞或副詞。你可取消「排除虛詞」。
- 篩選與排除設定只影響新開始的一輪，舊的未完成順序保留。干擾選項可來自整個同一題庫，不受測試目標開關限制。
- 第一次答對進入答對清單；答錯後須**連續答對 3 次**才回到答對清單，再次答錯才歸零。累計對錯不清掉，跨回合、重開仍保留。
- **每個項目每輪最多一次自動間隔重試。** 預設間隔 3 個其他已答項目，可調整。間隔不足或重試再錯就留待下次，不立即反覆出題；可另開錯題專練。
- 每日使用裝置本地日期；重試不增加不同項目數。重新整理會保留待答題或已評分畫面，不重複加分。未送出不算完成。
- 四選一必須有 4 個不同中文意思，且全來自同一題庫。不足時明示原因，單字／片語可改輸入英文。不用同義顯示文字當錯誤選項。
- 輸入英文忽略大小寫、前後／重複空白及智慧型撇號差異；不模糊猜測、不接受片段，不把所有變化詞形視為指定詞條的答案。

## 文法：原題與正式答案

進入「文法原題練習」，依分類或「只複習答錯原題」篩選。畫面呈現原始句子及原有選項，不再問英文文法名稱的中文翻譯。

例如來源題號是 24，而且摘錄有唯一對應的 `24` 標記，畫面會標出空格及題號。其他年份、數量不全部刪掉；數字有歧義或未找到空格時保持原文並提示。可展開原文核對。若來源只有摘錄而沒有完整文章，不會捏造上下文。

答案對照以**來源 ID＋年度＋題號**精確配對，並確認答案字母能對應原選項；不同年度、補考／正式考試不能混用。沒有答案、選項無法對應或尚未支援的複選答案，都不自行推測，只保存作答並標示未判分。

已核對的題目會保存對錯及三連對恢復狀態。未核對題目不計對錯。可以明確按「重新作答本題」，不會因重新整理就再計一次。文法原題採逐題作答與分類／錯題篩選，不套用單字的每日配額或自動間隔重試。

原來的 AI 文法理由只在作答後作參考，不能當作正式答案解析。替換答案對照不會偷偷重算過去的成績；如需依新答案評分，請重新作答。

## CSV 與私人檔案

請使用 UTF-8，接受 BOM、RFC 4180 的引號、逗號、雙引號跳脫與多行欄位。不是直接用逗號或換行切割。

| 題庫 | 必要欄位 | ID |
| --- | --- | --- |
| 按頻率單字 | `id,english,chinese,total_occurrences` | `word:...` |
| 按頻率片語 | 同上 | `phrase:...` |
| 文法分類及原題 | 同上，原題來自 `evidence_json` | 小寫英文字母開頭，後接小寫英數字／底線 |
| 分級單字 | `id,english,chinese,level` | `level-word:...` |
| 文法答案對照 | `source_id,year_roc,exam_type,variant,question,answer,answer_source` | 來源／年度／題號唯一 |

一般題庫頻率須為非負安全整數；未知大考中心級別留空，不當成 0 或猜測。來源多級別可用分號，例如 `2;4`，顯示完整分級並支援任一級別篩選。分級單字的 `level` 必須是 1–6，可用分號表示多個所屬級別；不要求頻率。

可選欄位有詞性、例句、翻譯來源及 `needs_review` 等。分級詞表的英文級別來自詞表，中文釋義另有來源；不要將補充詞典翻譯誤稱為官方中文。私人轉換稽核檔保留翻譯來源與待人工複核資訊。

本次分級 CSV 有 6,596 個去重詞條；選擇排除虛詞的檔案則為 6,521 個。少數詞條屬於多個級別，各級筆數加總不等於去重總數。級別依這次上傳 PDF，不套用另一份「111 學年度起適用」表。`level_source` 保存本次 PDF 檔名及雜湊識別，與中文的 `translation_source` 分開；完整備份也保留這項標識。

建議檔案對應：

| 匯入位置 | 本機資料檔 |
| --- | --- |
| 單字題庫 | `vocabulary-mobile-v2.csv`；如要在檔案中移除虛詞，可改用 `vocabulary-content-v2.csv` |
| 片語題庫 | 原來的 `phrases.csv` |
| 文法題庫 | 原來的 `grammar.csv` |
| 文法正式答案 | `grammar-answer-keys.csv`，目前 342 道可核對原題 |
| 分級單字題庫 | `graded-vocabulary.csv`；或已排除虛詞的 `graded-vocabulary-content.csv`，二選一 |

文法原始 367 筆註記去重後為 366 道，24 道非選擇／子題等不適用目前單一選項判分，維持未判分而不是默認答錯。原題與答案都只在使用者的裝置保存。

重新匯入先確認，整份驗證後才在同一 IndexedDB 交易中替換。相同 ID 保留歷史，移除 ID 的歷史會移除，未完成回合結束。文法重匯保留來源／年度／題號／頁碼仍相同的原題紀錄，只移除已不存在的原題；正式答案對照保留以供重新配對。仍請先備份。格式錯誤或儲存失敗不先刪舊資料。

第二版不顯示、不新存入 `source_locations_json`、`original_context_source_json`、`by_year_exam_counts_json` 等冗長逐次資訊。原始 CSV 請另外保留，不覆寫。另提供的 `vocabulary-mobile-v2.csv` 保留全部詞條與中英文字、例句及最小來源標記，體積約 2.24 MB，可優先在手機使用；`vocabulary-content-v2.csv` 另排除保守辨識的虛詞，會減少題庫列數，因此重匯前務必備份。

**不要將私人 CSV、答案 PDF、詞表 PDF、答案對照、完整 JSON 備份或翻譯稽核檔上傳 GitHub。** 網站程式不含這些資料。`.gitignore` 忽略 CSV、PDF、ZIP 及私有／測試產物目錄；JSON 備份仍應放在網站資料夾之外。

本批語料學測缺民國 109、114 年，英聽只有部分官方文字稿，所以頻率不是所有歷年考試的完整排名。多出來的答案 PDF 不會憑空補上欠缺的題目。

## 上傳 GitHub Pages（Windows 初學者）

本工作不會自動推送、合併、部署或更改 Pages。上傳到 `main` 才會更新目前的公開網站，請自行確認後操作。

1. 對程式碼 ZIP 按右鍵 → **全部解壓縮**。不要從 ZIP 視窗直接拖出，避免資料夾路徑遺失。
2. GitHub 儲存庫 `main` → Add file → Upload files。
3. 拖入解壓後的檔案及整個 `js` 資料夾。提交前確認清單有 `js/app.js`，而不只是根目錄的 `app.js`。
4. `index.html` 留在 repo 根目錄，不再套一層外資料夾。Commit changes 後等 Pages 部署完成。

保留原有「Deploy from a branch → main → /(root)」。必要檔案：

```text
index.html
styles.css
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
js/
  app.js
  data.js
  engine.js
  grammar.js
  speech.js
  import-worker.js
```

如果 GitHub 已把 JS 放到根目錄，可逐一使用鉛筆編輯，把檔名改成 `js/app.js` 等正確路徑。不要把 HTML、CSS 或 SW 搬入 `js`。

所有程式路徑相對，支援 `https://帳號.github.io/english-review/`。程式碼 ZIP 含上述檔案與 README，不含測試工具或私人資料；不用 Node 或 build。

### 更新及第一版資料

先匯出完整備份，再更新程式。第二版會遷移第一版資料，保留單字／片語紀錄與未完成回合，補上分級題庫；舊文法概念回合會結束，舊成績留在備份，不混成原題成績。

新版下載完成後按「安裝新版本」。它會重新載入，但不清空題庫；未送出的輸入可能要重填。資料庫版本升級時，舊分頁不能再用舊格式覆蓋新資料；如被其他分頁阻擋，關閉其他視窗重試。

最早的三張示範卡版本沒有更新按鈕：保持連線開啟一會，再關閉所有網站分頁及主畫面視窗重新開啟。**不要用清除網站資料當成例行更新方式。** 若檔案回傳 404，先修正上傳路徑，清快取無法補回缺少的程式檔。

離線快取只收本地程式和圖示，不抓私人 CSV、不用 CDN。只清除此應用相同 scope 的舊版快取，不刪同來源其他應用。

## 本機與開發測試

不能雙擊 `index.html` 用 `file://` 開啟模組／Worker。已安裝 Python 時，在網站資料夾執行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

用 `http://localhost:8000/` 預覽，Ctrl+C 停止；只綁本機，不對外公開。手機正式試用請用 HTTPS。

開發測試需要 Node.js 22 以上，部署不需要：

```powershell
npm ci
npm test
npm run test:browser
```

`CHROME_PATH` 可指定已安裝 Chromium／Chrome；瀏覽器測試在 `/english-review/` 子路徑運行。`PRIVATE_CSV_DIR` 可自願啟用本機三份來源的相容性測試，`VOCABULARY_CSV` 可改測手機精簡版，`LEVEL_CSV` 與 `GRAMMAR_KEYS_CSV` 可指定分級表與答案對照。`BROWSER_HEAP_MB=128` 可限制 Chromium 的 V8 堆積記憶體，但不是整台手機的記憶體測試。日誌只輸出數量而不輸出內容，不要把私人測試資料提交。

`scripts` 中的轉換工具供本機資料整理使用，不是網站執行依賴。詞表／答案 PDF 只在本機解析；不能把辨識失敗或待核實答案硬填成正解。

桌面 Chromium 的行動尺寸／記憶體限制測試不等同實體 Android 或 iPhone Safari。真機的語音、安裝、檔案選擇、可用記憶體與資料回收仍需實際試用；沒有可用離線語音時會明示，不能假裝已發音。
