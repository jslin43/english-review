# 英文複習：本機優先 PWA

繁體中文、免登入、免後端的單字／片語／文法複習工具。網站程式不含題庫；每位使用者自行匯入 CSV，資料只存在自己的瀏覽器 IndexedDB。不同裝置不會自動同步。

## 給第一次使用的人

1. 連線開啟網站，進入「設定與匯入」。
2. 分別選取單字、片語、文法的 UTF-8 CSV。等到畫面顯示「已匯入 N 筆」。不用把 CSV 上傳到 GitHub，也不用把檔案改成固定名稱。不能直接讀取 Downloads 裡未經你選取的檔案。
3. 回首頁，選「按頻率排序單字／片語／文法」，再按「開始這一輪」。
4. 單字與片語可選「看中文 → 輸入英文」或「看英文 → 四選一中文」。輸入答案後按 Enter 或確認；評分後再按下一題。沒有自動以「看答案」當作答對的功能。
5. 手機可加入主畫面。Android Chrome：選單 → 安裝應用程式／加到主畫面；iPhone Safari：分享 → 加入主畫面。請先等頁面下方顯示「離線資源已就緒」，再測試關閉網路。
6. 定期使用「匯出完整 JSON 備份」，在下載資料夾確認檔案存在。換手機時，在新手機匯入此備份即可還原。

**重要：** 瀏覽器清除資料、無痕模式、裝置空間不足或系統回收網站儲存，都可能影響資料。加入主畫面及「要求瀏覽器保留資料」不等於雲端備份。CSV 清單匯出是供閱讀用；完整還原必須使用 JSON 備份。

## 複習規則

- 預設每日不同項目目標：單字 20、片語 10、文法 5；優先舊項目數分別 5、3、2。可在設定調整為有效安全整數，沒有額外隱藏的題數上限；實際數量仍受題庫與資格限制。
- 「納入答對舊項目」與「納入答錯舊項目」預設都勾選。一般複習絕不拿未勾選的狀態補滿。新項目按數值頻率由高到低；相同頻率用穩定 ID 決定順序。曾經作答的項目不再當新項目。
- 有足夠合格舊項目時，先滿足設定的複習數量，優先較弱、較久未練習的項目；其他位置優先給新項目。新項目不足時才用允許的舊項目補足。每輪明確顯示新／舊數量。
- 每日計數依裝置的**本地日期**，不同項目當天只計一次；答錯也算練習。重開或重新整理不會再發一整輪新題。跨日繼續舊進度會明示，新作答計入當天。
- 第一次答對進入答對清單；任何一次答錯進入答錯清單。答錯項目要**連續答對 3 次**才回到答對清單；中途答錯歸零。累積答對／答錯次數不會被清掉。
- 答錯預設隔 **3 個其他已答項目**安排一次重試；可以設定間隔。每個項目每輪最多自動重試一次，以避免一直答錯造成無限練習。沒有足夠其他題時不立刻重複、不造出額外題，保留在答錯清單供下次練習。重試不增加不同項目計數；答對一次不會強制同輪刷滿恢復 3 次，可再開額外答錯複習。
- 「複習答錯的單字／片語／文法」只挑目前仍答錯的項目，支援隨機或頻率排序；每輪最多使用該題庫目標數。這是額外弱項練習，不受一般每日剩餘配額阻擋，但實際答過的項目仍計入當日學習統計。
- 四選一從**同一題庫**取出 4 個不同中文顯示文字，排除相同正解文字。不同詞條可有相同翻譯，因此不把同義顯示文字當干擾答案。整庫不足 4 個不同意思時會明示不可用；單字／片語可改為輸入英文。干擾選項不受舊項目開關限制。
- 輸入英文比對會忽略前後空白、重複空白、大小寫，並正規化智慧型撇號；只接受指定詞條，不模糊猜測、不接受子字串、不把所有 observed_forms 自動視為答案。
- 送出的答案與目前評分畫面一起原子保存。重新整理不會重複加分，未送出的輸入不算完成。可隨時「儲存並返回首頁」；多分頁的過期寫入會被拒絕，避免互相覆蓋。

### 文法第一版的安全範圍

文法練習是「英文概念 → 中文概念解釋」配對，並非原始學測／英聽題目的自動解題器。評分依匯入的類別配對。答題後可閱讀代表年份的原始材料、選項、來源與 AI 理由，**不宣稱有經核實的原題答案**。

原文數字、克漏字題號及年份原樣保留；例如題號前綴不能一律當成英文單字，也不能任意刪除所有數字。翻譯來源、需人工複核標記、級別狀態會在詳情呈現。缺少 CEEC 級別不當成 0，也不推測級別。

頻率只代表匯入語料。本批來源學測缺民國 109、114 年，13 份英聽卷中只有 1 份附官方聽力文字稿，因此不是全部歷年考試的完整出現頻率。

## CSV 匯入

使用 UTF-8（接受 BOM）、RFC 4180 格式：含逗號或換行的欄位必須用雙引號括住，欄位內的雙引號用兩個雙引號表示。支援 JSON 欄位與多行引文；不是直接用逗號或換行切開。

必要欄位為 `id,english,chinese,total_occurrences`。穩定 ID 必須符合題庫種類：單字 `word:...`、片語 `phrase:...`；文法類別 ID 使用小寫英文字母開頭，後接小寫英數字或底線，不加 `grammar:` 前綴。請優先使用來源工具產生的完整 CSV；選錯題庫、重複 ID、不正確數字／JSON 或不完整列會拒絕匯入。

頻率必須是非負安全整數，`ceec_level` 可留空或為 1–6，也支援來源以分號標註的多個級別（例如 `2;4`）。多級別原文完整顯示，篩選任一所屬級別都會找到；內部單值欄位採最低已標註級別，不會推測空白級別。會驗證選用的學測／英聽頻率欄位。支援例句、語境、來源、翻譯標記與文法證據等欄位，原始非空來源欄位完整保留。CSV 在 Web Worker 背景解析，清單採分頁，不一次建立數千列 DOM。

重新匯入前會要求確認。整份驗證完成才以 IndexedDB 單一交易取代；失敗或空間不足不會先刪掉原題庫。相同 ID 的紀錄保留，已刪除 ID 的歷史從此題庫移除，原題庫的未完成練習結束。請先備份，才不會失去移除項目的舊歷史。

完整備份有版本與結構驗證，含題庫、設定、紀錄及待續進度；還原前需確認，失敗不改原資料。備份只存一份題庫，不把原始證據重複塞進每筆進度。

**私人題庫、考題 PDF、CSV 及學習備份不可放進公開儲存庫。** `.gitignore` 已忽略 CSV、PDF、ZIP、`private-data/` 與測試產物。JSON 備份請放在網站資料夾以外；不要誤拖入 GitHub。

## 本機試用（Windows）

網站不需要建置、API Key、Node.js 或 npm 才能部署，但 ES modules、Worker、Service Worker 必須透過 HTTP/HTTPS 開啟，不能雙擊 `index.html` 使用 `file://`。

如果已安裝 Python，在本專案資料夾開啟 PowerShell：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

在此電腦瀏覽 `http://localhost:8000/`。這個命令只綁定本機，不公開到網際網路。按 Ctrl+C 停止。一般區域網路 HTTP 位址不符合手機 Service Worker 安全來源要求；手機正式試用請使用 HTTPS。

## 手動上傳到 GitHub Pages

本工作不會自動推送、合併、部署或修改 GitHub Pages。現在的線上網站仍由原本 `main` 分支內容決定。只有當你檢查並自行決定發佈後，才執行以下操作。

維持 GitHub Pages「Deploy from a branch → main → /(root)」即可，無建置流程。放在網站根目錄的必要檔案：

```text
index.html
styles.css
manifest.webmanifest
sw.js
icon-192.png
icon-512.png
js/
  app.js
  data.js
  engine.js
  import-worker.js
```

透過 GitHub 網頁 Upload files 時，保留 `js` 子資料夾。不要只更新 `index.html` 而漏掉 CSS／JS。所有路徑使用相對網址，支援 `https://你的帳號.github.io/english-review/` 子路徑。

`README.md`、`package.json`、`package-lock.json`、`tests/` 是說明與開發測試檔案，不是網頁執行依賴。**不要上傳 `node_modules`、私人 CSV／PDF／備份或測試產物。** 程式碼 ZIP 不含這些私人資料。

### 更新網站

1. 修改程式時，同時提高 `sw.js` 的 `CACHE_NAME` 版本（例如 `v2` → `v3`），新增模組也要加入 `ASSET_URLS`。
2. 將完整必要檔案一起更新。新離線資源全部下載成功才會就緒。
3. 使用者會看到「安裝新版本」，按下確認後重新載入。更新不清空 IndexedDB；未送出的文字／設定可能需重新輸入。
4. **從原始示範站第一次升級：** 舊示範程式沒有更新按鈕。如果仍看到示範卡片，請關閉所有此網站分頁／主畫面視窗，再連線重新開啟，讓等待中的新 Service Worker 啟用。不要用「清除網站資料」作為例行更新方式。

離線快取只包含程式殼層與本地圖示，不抓使用者 CSV、不呼叫 CDN 或外部翻譯服務。只清除此應用、此 scope 前綴的舊版快取，不刪除同一 GitHub Pages 來源上其他應用的快取。

## 開發與驗證

需要 Node.js 22 或較新版本。npm 套件只用於測試，不是網站執行依賴。

```powershell
npm ci
npm test
npm run test:browser
```

單元測試涵蓋 CSV／型別驗證、原子儲存、排程、三連對恢復、間隔重試、每日去重、選項與備份。瀏覽器測試用本機 Chromium，在 `/english-review/` 路徑運行，包含行動寬度、匯入、作答、重新載入及離線。Windows 預設尋找已安裝的 Chrome；也可用 `$env:CHROME_PATH='瀏覽器執行檔完整路徑'` 指定。

實際來源 CSV 只允許自願在本機做匯入冒煙測試：設定 `$env:PRIVATE_CSV_DIR='私人來源資料夾完整路徑'` 後執行 `npm run test:browser`，會讀取該資料夾的 `vocabulary.csv`、`phrases.csv`、`grammar.csv`。這是已知來源的相容性檢查，預期列數分別 6271／536／28，日誌只顯示數量，不輸出內容或私人截圖。來源不作為測試 fixture 提交。真實 iPhone Safari／Android 手機與作業系統的安裝、檔案選擇及儲存回收行為仍應由使用者試用確認；桌面行動尺寸模擬不代表真機驗證。

### 模組

| 檔案 | 功能 |
| --- | --- |
| `js/data.js` | RFC 4180 CSV、題庫與備份驗證、IndexedDB 原子讀寫、清單匯出 |
| `js/import-worker.js` | 背景匯入解析 |
| `js/engine.js` | 純函式排程、選項、答案比對、恢復狀態、重試及每日計數 |
| `js/app.js` | 繁體中文畫面、互動、匯入／備份、分頁清單、更新通知 |
| `sw.js` | 子路徑安全的版本化離線程式快取 |
